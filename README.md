# JAVASCRIPT MUSIC PLAYER

A simple and interactive music player built using **HTML, CSS, and JavaScript** to practice basic string and array methods while creating a functional web application.

## About

This project focuses on learning JavaScript fundamentals by building a browser-based music player. It demonstrates how arrays can store song information, string methods can process text, and JavaScript can update webpage elements dynamically.

## Purpose

The purpose of this project is to strengthen JavaScript fundamentals by applying string and array methods to a practical music player project.
